# Snake Game in Java 🐍

A simple and classic **Snake Game** built with Java using `Swing` for the GUI.

## 🕹 Gameplay

- Use the arrow keys to control the snake (↑ ↓ ← →).
- Eat the red apples to grow your snake and increase your score.
- Avoid running into the walls or yourself — or it's **Game Over**!

## 🚀 Features

- Dynamic apple spawning
- Score display
- Game Over screen
- Basic keyboard controls

## 🛠 Requirements

- Java JDK 8 or higher

## ▶️ How to Run

1. Compile the Java files:

```bash
javac Gioco/*.java
```

2. Run the game:

```bash
java Gioco.SnakeGame
```

## 📁 Project Structure

```
Gioco/
├── GameFrame.java
├── GamePanel.java
└── SnakeGame.java
```
